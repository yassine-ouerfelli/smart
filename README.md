# Smart — Company Website

A server-rendered company website with a product catalogue stored in MongoDB.

## Features
- Home, About, Solutions and Contact pages
- Product list and product detail pages loaded from MongoDB
- Form to add new products
- Shared header and footer with EJS partials

## Tech stack
Node.js · Express · EJS · MongoDB · Mongoose · express-session

## Getting started
```bash
git clone https://github.com/yassine-ouerfelli/smart.git
cd smart
npm install
node server.js
```
The site runs on http://localhost:6001. You need a running MongoDB instance.
